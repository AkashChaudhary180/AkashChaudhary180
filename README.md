## 🌱 AgriHeal – AI-Powered Crop Disease Diagnosis System

An AI-powered crop disease diagnosis platform that helps users identify possible crop diseases using crop selection and symptom descriptions.

The system combines **OOP-based rule matching** with a **Groq LLM fallback** for previously unmatched symptoms.

**Tech Stack:** Node.js · Express.js · JavaScript · HTML · CSS · Groq API · Render

### Key Features

* 🌾 Crop-based disease diagnosis
* 🔍 Symptom keyword matching
* 🧠 Object-oriented diagnosis engine
* 🦠 Fungal, bacterial and viral disease classification
* 🤖 Groq AI fallback for unmatched symptoms
* 💊 Treatment and pesticide recommendations
* 🛡️ Prevention guidance

🔗 **[View Repository](https://github.com/AkashChaudhary180/Agriheal1)**

🔗 **[Live Demo](https://agriheal1.onrender.com)**
